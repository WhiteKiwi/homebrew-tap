# Whitekiwi Tap

Personal Homebrew tap for WhiteKiwi formulae.

## Available Formulae

- **[locron](https://github.com/WhiteKiwi/locron)**: Local-first job scheduler for macOS and Linux.

## Installation

```sh
brew tap whitekiwi/tap
brew trust whitekiwi/tap   # newer Homebrew requires trusting third-party taps
brew install locron
```

Or install directly:

```sh
brew tap whitekiwi/tap && brew trust whitekiwi/tap && brew install locron
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
